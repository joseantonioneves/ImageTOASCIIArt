# ImageToASCIIconverter

Este projeto tem como objetivo converter imagens em arte ASCII utilizando Windows Forms.  
A aplicação permite ao usuário selecionar uma imagem, processá-la e gerar uma representação em texto ASCII, que pode ser visualizada e copiada.

## Funcionalidades

- Seleção de imagens do computador
- Conversão automática da imagem para arte ASCII
- Visualização do resultado em tempo real
- Opção para copiar ou salvar o texto gerado

## Tecnologias

- .NET (WinForms)
- C#

## Como executar

1. Clone este repositório.
2. Abra a solução no Visual Studio ou utilize o terminal.
3. Execute o comando:
   ```
   dotnet run
   ```
4. Siga as instruções na interface gráfica.

## Finalidade

O projeto serve como exercício prático de manipulação de imagens, processamento de pixels e desenvolvimento de interfaces gráficas com .NET, além de demonstrar a conversão de imagens para arte ASCII.
